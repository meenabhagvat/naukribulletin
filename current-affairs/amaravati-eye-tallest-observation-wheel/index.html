Amaravati Eye to Become India's Tallest Observation Wheel

Exam Relevance: All

Summary

The Amaravati Eye, a 139-metre riverfront attraction, is set to become India's tallest observation wheel, surpassing the London Eye. This project is planned under a Public-Private Partnership (PPP) model, which is a key concept in Indian economy and governance. The project's success can have implications for India's tourism and infrastructure development.

📌 Key Facts for Exam

  • 139-metre tall
  • Riverfront attraction
  • PPP model
