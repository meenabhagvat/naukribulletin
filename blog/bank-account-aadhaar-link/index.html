Bank Account Mein Aadhaar Link Kaise Kare 2026 — All Banks

By NaukriBulletin Team

Why Link Aadhaar to Bank Account?

  • DBT (Direct Benefit Transfer) — government money comes directly to Aadhaar-linked bank account
  • LPG subsidy — linked to bank via NPCI
  • Scholarship — credited via DBT
  • PM Kisan, Ladli Behna, pension — all use Aadhaar-linked bank

Method 1: Bank Branch (Most Reliable)

Works for all banks:

1. Visit your bank branch with original Aadhaar card
2. Ask for "Aadhaar Seeding Form" / "Aadhaar Linking Form"
3. Fill form with account number + Aadhaar number
4. Submit with photocopy of Aadhaar
5. Bank links within 2-3 working days
6. You get SMS confirmation

Method 2: SBI (State Bank of India)

Via Net Banking:

1. Login to onlinesbi.sbi
2. "My Account & Profile" → "Update Aadhaar"
3. Enter Aadhaar number → verify OTP
4. Done instantly

Via SBI YONO App:

1. Open YONO → "Services" → "Aadhaar Seeding"
2. Enter Aadhaar → OTP → Done

Via ATM:

1. Insert card → PIN → "Services" → "Aadhaar Seeding"
2. Enter Aadhaar number → confirm

Method 3: PNB (Punjab National Bank)

Via Net Banking:

1. Login to PNB net banking
2. "Value Added Services" → "Aadhaar Seeding"
3. Enter Aadhaar → OTP → Done

Via PNB ONE App:

Similar process in app

Method 4: Bank of Baroda

Via BOB World App:

"Services" → "Link Aadhaar" → enter Aadhaar → OTP

Method 5: Canara Bank

Via Net Banking: Login → "Aadhaar Seeding" → Enter details → OTP

Check Aadhaar-Bank Link Status

1. Visit resident.uidai.gov.in
2. "Aadhaar Services" → "Bank Seeding Status"
3. Enter Aadhaar + OTP
4. Shows which bank is linked

Common Issues

Issue: Aadhaar seeding done but DBT not received

  • Check if NPCI mapping is active (same step above)
  • Ensure bank account is active (not dormant)

Issue: Multiple bank accounts

  • Only ONE bank can be primary NPCI-mapped at a time
  • Latest seeding overrides previous
💡 Tip: Do Aadhaar seeding at the bank where you want to receive government money — this becomes your "primary DBT account."

Key Helplines

  • PNB: 1800-180-2222
